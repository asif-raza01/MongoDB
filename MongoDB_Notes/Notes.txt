Database->Physical layer where data actually gets stored.
Database Management System->An application or software whhich is used to manage the database.

DBMS types:
1.RDBMS
2.NoSql DBMS

RDBMS:
1.STORES DATA IN FORM OF TABLES(ROWS AND COLUMN).
2.TRANSACTIONS
3.FIXED SCHEMA

NOSqlDBMS:
1.KEY-VALUE
2.DOCUMENT(MONGODB USES THIS JSON LIKE(BSON))
3.COLUMNAR
4.GRAPHDB


MONGODB:
1.FREE OPENSOURCE STORES DATA IN JSON LIKE FORMAT(BSON)
2.FLEXIBLE SCHEMA DOES NOT REQUIRES FIXED SCHEMA
3.MONGODB ALSO LET US STORE RELATED DATA INSIDE SAME DOCUMENT USING EMNEDDED FIELDS.
